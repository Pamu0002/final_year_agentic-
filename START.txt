LOCAL WEB STARTUP (Windows PowerShell)

Full instructions: README.md

1. Start PostgreSQL and create the agent_platform database.
2. Configure backend/.env, ai-service/.env, and frontend/.env.local.
3. Start each service in a separate PowerShell window:

AI service:
  cd ai-service
  .\.venv\Scripts\Activate.ps1
  uvicorn main:app --host 127.0.0.1 --port 8000 --reload

Backend:
  cd backend
  npm run dev

Frontend:
  cd frontend
  npm run dev -- -p 3001

Open http://localhost:3001
